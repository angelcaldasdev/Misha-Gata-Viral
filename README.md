# 🐾 Misha la Gata Viral

Página web hecha como proyecto práctico del curso de **Desarrollo Front-End** (Ministerio de Trabajo y Promoción del Empleo), aplicando HTML, CSS y JavaScript desde cero.

🔗 **Demo en vivo:** https://angelcaldasdev.github.io/Misha-Gata-Viral/

![Estado](https://img.shields.io/badge/estado-en%20desarrollo-orange)

## 📖 Sobre el proyecto

Misha es mi gata, y esta página nació como ejercicio para poner en práctica cada módulo del curso: estructura HTML, estilos con CSS (selectores, colores, diseño responsivo), y lógica con JavaScript (variables, funciones, eventos y manejo del DOM). Con el tiempo se fue convirtiendo en un pequeño proyecto real, con funcionalidades que fui agregando por mi cuenta para seguir aprendiendo.

## ✨ Funcionalidades

- **Sección de inicio** con foto destacada y datos de Misha
- **Galería con carrusel** de fotos, con flechas y soporte de deslizado táctil (swipe)
- **Formulario de suscripción** por correo, con validación en JavaScript
- **Sección de donaciones** con QR de Yape y datos bancarios, para quienes quieran colaborar con su comida
- **Enlace a Instagram** de Misha
- **Diseño responsivo**, adaptado a celular y escritorio

## 🛠️ Tecnologías usadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, diseño responsivo con media queries, variables CSS)
- JavaScript (vanilla, sin frameworks) — manipulación del DOM, eventos, `localStorage`
- Google Fonts (Baloo 2 y Nunito)
- Publicado con GitHub Pages

## 🚀 Cómo verlo localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/angelcaldasdev/Misha-Gata-Viral.git
   ```
2. Abre `index.html` en tu navegador (o usa la extensión "Live Server" de VS Code).

## 📚 Contexto de aprendizaje

Este proyecto forma parte de mi camino como **Fullstack Java Developer** (Java, Spring Boot, Angular, TypeScript). Lo construí mientras cursaba el módulo de Front-End del curso del Ministerio de Trabajo, reforzando también con práctica adicional por mi cuenta.
